# JDGF Research Workspace

This directory separates research evidence and publication work from the authoritative framework documentation in `docs/`.

## Proposed structure

- `literature-review/` — search strategies, screening, synthesis, and evidence maps;
- `working-papers/` — working papers derived from or testing JDGF;
- `articles/` — journal manuscripts and submission records;
- `doctoral-research/` — proposal, methodology, empirical work, and validation materials.

## Rules

- Research drafts do not automatically modify the authoritative framework.
- Framework changes derived from research must be justified and recorded through a focused pull request.
- References used to support validated framework decisions belong in `docs/08-references/`.
- Confidential empirical material must not be committed to the public repository.
