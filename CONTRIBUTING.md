# Contributing to JDGF

## Purpose

Contributions must strengthen the Judicial Data Governance Framework as a scientific, methodological, and institutionally applicable framework.

## Before contributing

Confirm that the proposed change:

1. addresses a real judicial data-governance need;
2. does not duplicate existing content;
3. fits the approved JDGF architecture;
4. can be implemented in real judicial institutions;
5. respects the human-centered philosophy of the project;
6. distinguishes data governance, digital transformation, and AI governance.

## Contribution types

- conceptual clarification;
- literature and standards references;
- framework dimensions and controls;
- maturity-model criteria;
- assessment instruments;
- implementation guidance;
- case studies;
- editorial corrections and translations.

Software products, predictive-justice systems, machine-learning models, and commercial product integrations are outside this repository's scope.

## Document requirements

Major documents should include:

- purpose;
- scope;
- definitions;
- assumptions;
- references;
- version;
- author or contributor;
- revision history.

Use clear academic language. Avoid unsupported claims, marketing language, unnecessary jargon, and conceptual duplication.

## Workflow

1. Open or reference an issue describing the need.
2. Create a focused branch.
3. Modify the smallest coherent set of documents.
4. Update `CHANGELOG.md` when the change is notable.
5. Submit a pull request explaining the rationale, dependencies, risks, and validation performed.

## Review criteria

A contribution is ready to merge when it is coherent, referenced where necessary, non-duplicative, realistic for judicial institutions, and aligned with the path to JDGF v1.0.
