# Changelog

All notable changes to the Judicial Data Governance Framework (JDGF) are documented in this file.

The project follows a documentation-first lifecycle:

**Draft → Working Draft → Review → Validated → JDGF v1.0**

## [Unreleased]

### Added

- Repository governance and contribution documentation.
- Structured documentation architecture for JDGF v1.0.
- Framework, maturity-model, assessment, implementation, glossary, case-study, reference, and validation materials.
- Repository-wide scientific audit and v1.0 readiness assessment.
- Structured expert-review and cognitive-testing materials.

### Changed

- Harmonized the repository purpose, scope, terminology, and project positioning.
- Consolidated the framework around eight governance dimensions and six recurring capability attributes.
- Replaced the preliminary repository audit with a current audit covering scientific coherence, assessment ambiguity, reference architecture, pilot readiness, and release blockers.
- Removed tool-specific drafting metadata from the public repository structure while preserving substantive artificial-intelligence governance content.

### Removed

- Tool-specific project instruction file that was not part of the JDGF scientific corpus.
