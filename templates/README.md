# JDGF Templates

This directory will contain reusable, version-controlled instruments supporting assessment, implementation, reporting, review, and governance.

Planned templates include:

- institutional profile;
- stakeholder and responsibility matrix;
- evidence register;
- assessment questionnaire;
- maturity scoring worksheet;
- risk and gap register;
- improvement plan;
- decision log;
- assessment report;
- framework document metadata and revision history.

Every template must state its purpose, version, intended users, instructions, required evidence, confidentiality classification, and relationship to the relevant JDGF document.
