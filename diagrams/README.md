# JDGF Diagrams

This directory contains authoritative visual representations of the framework, governance model, assessment cycle, maturity progression, data lifecycle, and implementation roadmap.

## Rules

- Maintain an editable source for every diagram.
- Use terminology from `docs/07-glossary/`.
- Link diagrams to the authoritative document they explain.
- Do not use diagrams to introduce concepts absent from the written framework.
- Record substantive diagram changes in `CHANGELOG.md`.
