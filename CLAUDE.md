# CLAUDE.md — Judicial Data Governance Framework (JDGF)

## Version

- Version: 1.0 (Draft)
- Project: Judicial Data Governance Framework (JDGF)
- Programme: Institutional Governance Research Program (IGRP)
- Parent programme: Programme Magnifica Humanitas

## 1. Purpose

This repository contains the research, documentation, and scientific development of the **Judicial Data Governance Framework (JDGF)**.

The purpose of this repository is not to develop software. Its purpose is to build, document, validate, and publish a scientific framework dedicated to judicial data governance.

Every contribution must strengthen the framework.

## 2. Mission

Help design a complete governance framework allowing judicial institutions to:

- organize judicial data;
- improve data quality;
- clarify responsibilities;
- strengthen decision-making;
- support digital transformation;
- prepare responsible AI adoption.

## 3. Project Philosophy

Technology is never the objective.

Technology supports institutions. Institutions support justice. Justice serves people.

Therefore:

**Human → Institution → Governance → Data → Digital → AI**

Never reverse this order.

## 4. Scope

JDGF focuses on:

- Judicial Data Governance;
- Institutional Governance;
- Data Quality;
- Metadata;
- Data Lifecycle;
- Data Stewardship;
- Data Ownership;
- Security;
- Privacy;
- Judicial Statistics;
- Information Management;
- Digital Transformation;
- Responsible AI Readiness.

Outside the scope:

- software implementation;
- predictive justice;
- AI algorithms;
- machine learning models;
- commercial products.

## 5. Repository Objective

The repository should progressively become the official reference for JDGF.

Expected outputs include:

- scientific framework;
- conceptual model;
- governance principles;
- maturity model;
- assessment methodology;
- implementation guide;
- indicators;
- glossary;
- publications;
- case studies;
- doctoral research support.

## 6. Working Principles

Always:

- improve existing content before creating new content;
- preserve conceptual consistency;
- document assumptions;
- justify design decisions;
- identify dependencies;
- produce reusable documentation.

Never:

- invent unnecessary concepts;
- duplicate existing sections;
- over-engineer the framework;
- introduce technology without institutional justification.

## 7. Scientific Position

The JDGF is a governance framework.

It is neither:

- software;
- a methodology alone;
- a maturity model alone;
- a standard alone.

It integrates these elements into a coherent governance framework.

## 10. AI Usage Policy

Artificial intelligence assists research.

It never replaces:

- literature review;
- critical thinking;
- scientific judgement;
- institutional expertise.

Whenever AI-generated assumptions appear, identify them explicitly.

## 11. Decision Rules

Before proposing any new component, verify:

- Does it solve a real governance problem?
- Is it compatible with JDGF?
- Does it duplicate existing work?
- Can judicial institutions realistically implement it?
- Does it improve the framework?

When the answer is uncertain, improve the existing framework instead.
