# JDGF Assessment Methodology

## Status

**Working Draft — instruments and scoring remain to be validated**

## Purpose

The JDGF assessment determines how judicial data is currently governed, identifies material gaps and risks, establishes an evidence-based maturity profile, and supports a prioritized improvement plan.

## Assessment cycle

1. **Mandate and scope** — define institution, services, data domains, objectives, authority, safeguards, and exclusions.
2. **Preparation** — identify stakeholders, evidence sources, interviewees, schedule, and confidentiality arrangements.
3. **Evidence collection** — review documents and systems, conduct interviews and workshops, observe practices, and sample records.
4. **Analysis** — assess each framework dimension against defined criteria and evidence thresholds.
5. **Validation** — test findings with accountable institutional actors and document disagreements or evidence gaps.
6. **Reporting** — present strengths, risks, maturity levels, priority actions, dependencies, and limits.
7. **Improvement follow-up** — assign actions, indicators, owners, deadlines, and review cycles.

## Core instruments to develop

- institutional profile form;
- document and evidence request list;
- stakeholder interview guides;
- dimension-based assessment questionnaire;
- evidence register;
- scoring and confidence worksheet;
- risk and gap register;
- maturity profile;
- improvement-plan template;
- executive and detailed report templates.

## Evidence rules

Assessment conclusions should distinguish:

- verified evidence;
- self-reported practice;
- partial evidence;
- unavailable evidence;
- assessor inference;
- unresolved disagreement.

No maturity rating should rely exclusively on aspiration, policy text without implementation evidence, or unsupported self-assessment.

## Ethical and institutional safeguards

- protect confidential, personal, and security-sensitive information;
- minimize collection of case-level data unless strictly necessary;
- define access and retention arrangements for assessment evidence;
- avoid disrupting judicial independence or operational responsibilities;
- present limitations and conflicts of interest transparently;
- obtain appropriate institutional authorization.

## Expected outputs

- assessment scope statement;
- evidence register;
- dimension-by-dimension findings;
- maturity profile with confidence notes;
- prioritized risks and gaps;
- improvement roadmap;
- validation record;
- final institutional report.
