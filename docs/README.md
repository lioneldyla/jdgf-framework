# JDGF Documentation

This directory contains the authoritative documentation for the Judicial Data Governance Framework.

## Documentation architecture

1. [`01-foundations/`](01-foundations/) — problem statement, vision, objectives, scope, principles, and theory of change.
2. [`02-framework/`](02-framework/) — concepts, dimensions, actors, responsibilities, processes, controls, and indicators.
3. [`03-maturity-model/`](03-maturity-model/) — maturity levels, criteria, scoring principles, and progression logic.
4. [`04-assessment/`](04-assessment/) — diagnostic method, instruments, evidence requirements, and reporting.
5. [`05-implementation/`](05-implementation/) — adoption roadmap, governance setup, improvement planning, and monitoring.
6. [`06-case-studies/`](06-case-studies/) — empirical applications and lessons learned.
7. [`07-glossary/`](07-glossary/) — controlled terminology and definitions.
8. [`08-references/`](08-references/) — scientific literature, standards, and institutional sources.

## Source-of-truth rules

- Each concept must have one authoritative definition.
- Cross-cutting material must link to the authoritative document rather than duplicate it.
- Draft proposals must be clearly labelled.
- Substantive changes must be recorded in `CHANGELOG.md`.
- The repository root explains the project; this directory contains the framework itself.

## Status

The documentation is currently a **working draft** being consolidated toward **JDGF v1.0**.
